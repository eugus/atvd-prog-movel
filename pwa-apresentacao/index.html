SERVICE WORKER

O intermediário entre a aplicação e a rede

Durante a instalação, o Service Worker salva os arquivos essenciais. Quando a página solicita um recurso, o evento fetch procura primeiro uma resposta adequada e permite usar o cache quando a rede não está disponível.

O projeto também usa o evento activate para remover versões antigas do cache.

TESTE OFF-LINE

Como comprovar que funciona

  1. Abra o projeto usando um servidor local em localhost.
  2. Abra o DevTools → Application → Service Workers e confirme que o worker está ativado.
  3. Recarregue a página uma vez para garantir que os arquivos foram armazenados.
  4. Em DevTools → Network, marque Offline e atualize a página.
  5. A página continuará sendo exibida usando os arquivos salvos no cache.
